⚡ الطريقة 1: PWA (الأسرع والأسهل)

✅ مميزات PWA: فوري، يعمل Offline، تحديثات تلقائية، لا يحتاج بناء

📱 على Android:

1 افتح Chrome على هاتفك
2 ادخل على: https://sudan-online-store.vercel.app
3 اضغط على القائمة (⋮) في أعلى يمين Chrome
4 اختر "تثبيت التطبيق" أو "Add to Home Screen"
5 اضغط "تثبيت" وسيظهر التطبيق على الشاشة الرئيسية!

🍎 على iPhone (iOS):

1 افتح Safari وادخل على الموقع
2 اضغط على زر المشاركة (مربع مع سهم لأعلى)
3 اختر "إضافة إلى الشاشة الرئيسية"
4 اضغط "إضافة"

💻 على الكمبيوتر:

1 افتح Chrome أو Edge
2 اضغط على أيقونة التثبيت في شريط العنوان (يمين)
3 اختر "تثبيت"

📦 الطريقة 2: بناء APK (للمطورين)

⚠️ متطلبات: Node.js 18+، Java JDK 17+، Android SDK

🚀 البناء التلقائي (موصى به):

# 1. تحميل المشروع
git clone https://github.com/tajalsir2026-byte/Sudan-Online-Store.git
cd Sudan-Online-Store/android-builds

# 2. إعطاء صلاحيات
chmod +x build-all.sh

# 3. تشغيل السكريبت
./build-all.sh

# 4. ستجد 3 ملفات APK:
# - sanad-admin.apk (إدارة المنصة)
# - sanad-merchant.apk (تاجر السند)
# - sanad-client.apk (تطبيق الجمهور)

🔧 البناء اليدوي (تطبيق واحد):

# بناء تطبيق الإدارة:
cd android-builds/admin-app
npm install
npx cap sync android
cd android
./gradlew assembleDebug
cd ..
cp android/app/build/outputs/apk/debug/app-debug.apk ../sanad-admin.apk

🔧 حل المشاكل

❓ PWA: "تثبيت التطبيق" غير ظاهر

تأكد من استخدام Chrome (ليس Firefox/Safari)
تأكد من أن الموقع HTTPS (ليس HTTP)
جرب: الإعدادات → تطبيقات الويب → تثبيت

❓ APK: JAVA_HOME is not set

export JAVA_HOME=/usr/lib/jvm/java-17-openjdk

❓ APK: SDK location not found

export ANDROID_HOME=$HOME/Android/Sdk
echo "sdk.dir=$ANDROID_HOME" > android/local.properties

❓ APK: Gradle build failed

./gradlew clean
./gradlew assembleDebug
